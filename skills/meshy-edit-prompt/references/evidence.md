## How the request looks inside

`POST /meshyd-api/web/v2/tasks/{base}/model-edit` with `args.modelEdit = {target: "selection", selectionCells: [[x, y, z], …] on a 16-unit grid, prompt, userView: [camera direction]}`. The result carries `result.modelEdit.optimizedPrompt`, a language-model rewrite for an image-edit model. Excerpts:

- Run 5, "raven on shoulder": "Add a single small sculpted white-clay raven perched firmly atop the knight's right pauldron (viewer's left shoulder, near x=430, y=470)."
- Run 7, template: "Add a small stylized raven perched directly on the knight's left shoulder armor (screen-right pauldron, above the shield arm)."
- Run 9, "make it thicker": "Modify the miniature knight figure to make its proportions distinctly stockier, chunkier, and thicker. Thicken the torso, waist, and hips outward…"
- Run 11, template: "Modify only the sword blade held in the knight's right hand… Make the blade twice as wide across its flat face and twice as thick in cross-section…"
- Every run: "Keep the knight miniature's body, armor, cape, sword, shield, legs, and stone circular base strictly identical…"
